# Справочник — он же граница компетенции

Три папки, и они не смешиваются.

| Папка | Что внутри | Входит ли в вычисления |
|---|---|---|
| `signs/` | значения знаков и табличек, 40 записей | да, это **белый список** |
| `general_rules/` | правила, которых на знаке нет, 11 заметок | **никогда** |
| `sources/` | разбор исходных материалов | нет, это рабочие документы |

## `signs/` — белый список

Один файл на запись, имя файла — ключ. Чего в этой папке нет, продукт **не интерпретирует**:
показывает дословно и снижает уверенность. Это не пробел, а объявленная граница
компетенции: исчерпывающего перечня шведских табличек не существует, их текст задаёт
муниципалитет.

### Формат файла

```
---
key: avgift
tokens: Avgift
category: rule
schema: parsed.fee=true
en: The sign requires payment for parking during this period
source: Transportstyrelsen, «Stanna och parkera»
---

Человеческое объяснение по-русски.
```

Заголовок между `---` — простые пары `ключ: значение`, разбираются десятью строками кода
без внешних зависимостей. Тело — Markdown для человека.

| Поле | Зачем |
|---|---|
| `key` | по нему запись читается; обязан совпадать с именем файла |
| `tokens` | что написано на знаке |
| `category` | `main_sign` · `rule` · `info` · `not_interpreted` |
| `schema` | какому полю `schema/sign.schema.json` соответствует |
| `en` | **готовый текст для интерфейса**: язык интерфейса английский |
| `source` | откуда взято значение |

### Поле `en` — не украшение

Текст ответа собирается кодом **из этих строк**, поэтому запрещённая формулировка
физически не может прийти из ответа модели. Каждая строка — утверждение о **знаке**,
а не о пользователе: «The sign designates these spaces for motorcycles», но никогда
«you cannot park here». Проверяется тестом на запрещённые шаблоны.

### Категории

- **`main_sign`** — верхняя панель. Среди них два указателя направления, которые
  стоянки **не разрешают вовсе**: их легко принять за `P`.
- **`rule`** — задаёт правило, попадает в движок.
- **`info`** — распознаётся и объясняется, но правил не задаёт и уверенность
  **не снижает**: оператор с телефоном, `Boende`, платёжное табло.
- **`not_interpreted`** — прочитано и показано дословно, но смысл продукт не присваивает:
  номер тарифа, код зоны.

## `general_rules/` — справка, а не правила движка

Расстояния до перекрёстка, где нельзя стоять, что считается стоянкой, кому нельзя
под обычным `P`. В каждом файле стоит пометка «**на знаке этого нет** — проверьте сами»,
и она обязательна: смешать эти правила с разбором знака значило бы вернуться
к вынесению вердикта.

## `sources/`

`SIGNS_CATALOGUE.md` — значения знаков по брошюре Transportstyrelsen «Stanna och parkera»,
основной источник для `signs/`. `RULES_SOURCE.md` — общие правила по учебнику
`Körkortsboken`, основной источник для `general_rules/`. В спорном месте прав каталог:
он опирается на публикацию регулятора.
